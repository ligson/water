# Auth Scene Photo Assets

These photos are bundled locally so the lock screen stays self-hosted and does not depend on remote image loading.

- `riverbed-stones.jpg`: "Ganges river pebbles diff 16k" by Amal Kumar via Poly Haven, Wikimedia Commons, CC0. The bundled copy is resized and converted to JPEG for web delivery.
  Source: https://commons.wikimedia.org/wiki/File:Ganges_river_pebbles_diff_16k_(Amal_Kumar_via_Poly_Haven).png
- `riverbed-water.jpg`: former photographic water reference, retained for visual comparison but no longer loaded by the lock screen.
  Source: https://commons.wikimedia.org/wiki/File:A_Variety_of_River_Stones_Beneath_a_Thin_Layer_of_Water_in_a_Stream.JPG
- `fish-carp-top.png`: cropped transparent overhead common carp photograph by Team Korda, Flickr, CC BY 2.0. The fish is oriented head-first to the right for the left-to-right shader path.
  Source: https://www.flickr.com/photos/159335283@N06/43123811362
- `fish-koi-top.png`: cropped transparent overhead koi photograph by VangieAdH, Flickr, CC BY 2.0. The fish is oriented head-first to the left for the right-to-left shader path.
  Source: https://www.flickr.com/photos/60139822@N00/398942977
