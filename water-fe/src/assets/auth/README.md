# Auth Scene Photo Assets

These photos are bundled locally so the lock screen stays self-hosted and does not depend on remote image loading.

- `riverbed-stones.jpg`: "Ganges river pebbles diff 16k" by Amal Kumar via Poly Haven, Wikimedia Commons, CC0. The bundled copy is resized and converted to JPEG for web delivery.
  Source: https://commons.wikimedia.org/wiki/File:Ganges_river_pebbles_diff_16k_(Amal_Kumar_via_Poly_Haven).png
- `riverbed-water.jpg`: former photographic water reference, retained for visual comparison but no longer loaded by the lock screen.
  Source: https://commons.wikimedia.org/wiki/File:A_Variety_of_River_Stones_Beneath_a_Thin_Layer_of_Water_in_a_Stream.JPG
- `fish-carp-top.png`: former cropped transparent overhead common carp photograph, retained for visual history but no longer loaded by the lock screen. Photo by Team Korda, Flickr, CC BY 2.0.
  Source: https://www.flickr.com/photos/159335283@N06/43123811362
- `fish-koi-top.png`: former cropped transparent overhead koi photograph by VangieAdH, Flickr, CC BY 2.0. It is retained for visual history but is no longer loaded by the lock screen.
  Source: https://www.flickr.com/photos/60139822@N00/398942977
- `fish-koi-kohaku-right.png`: foreground-extracted photograph "Marudo Sandan Kohaku" by KoiQuestion, Flickr, CC BY-SA 2.0; oriented head-first to the right.
  Source: https://www.flickr.com/photos/54028598@N06/5848224384
- `fish-koi-showa-left.png`: foreground-extracted photograph "SFF Maruten Showa 76cm" by KoiQuestion, Flickr, CC BY-SA 2.0; oriented head-first to the left.
  Source: https://www.flickr.com/photos/54028598@N06/6303053179
- `fish-koi-yamabuki-right.png`: foreground-extracted photograph "Yagenji Ginrin yamabuki Ogon 70cm" by KoiQuestion, Flickr, CC BY-SA 2.0; oriented head-first to the right.
  Source: https://www.flickr.com/photos/54028598@N06/6317739221
- `fish-koi-shiro-left.png`: foreground-extracted photograph "Omosako Shiro Utsuri 48cm" by KoiQuestion, Flickr, CC BY-SA 2.0; oriented head-first to the left.
  Source: https://www.flickr.com/photos/54028598@N06/6303052675

The four active koi textures come from four different real fish photographs. Local processing is limited to foreground extraction, transparent-edge cleanup, rotation, cropping, and web-size optimization; no synthetic recoloring or painted pattern replacement is applied.
